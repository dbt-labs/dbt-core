## 2.0.0-dev.23

Released August 07, 2026

### Fixes

- fix: explicitly set default empty variable for $SHELL so that the script will not end while setting the $SHELL.
- Fix typo in the `try_or_compiler_error` type-check warning message ("a optional argument argument" -> "an optional argument") ([#15323](https://github.com/dbt-labs/dbt-core/issues/15323))
- Fix the `@` graph operator (and the equivalent `childrens_parents` YAML selector) returning an empty set when applied to a leaf node. It now correctly returns the node together with its ancestors. ([#15280](https://github.com/dbt-labs/dbt-core/issues/15280))
- Fix source freshness failing entirely when a single source errors in the MapReduce aggregation phase. ([#15385](https://github.com/dbt-labs/dbt-core/issues/15385))
- dbt init no longer leaves a stale authenticator field when switching from SSO/MFA to Password or Key pair authentication for Snowflake profiles ([#15378](https://github.com/dbt-labs/dbt-core/issues/15378))
- Normalize BigQuery model context column data types when contract `alias_types` is enabled (e.g. `FLOAT` -> `FLOAT64`), matching dbt Core. ([#14097](https://github.com/dbt-labs/dbt-core/issues/14097))
